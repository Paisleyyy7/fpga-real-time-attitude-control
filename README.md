# 芯衡随动

2026 年全国大学生嵌入式芯片与系统设计竞赛 FPGA 创新设计赛道选题一项目代码。

本仓库保存本队提交的 Verilog 源码和演示视频。顶层模块为 `top`，输入包括 50 MHz 时钟、按键、10 位 ADC 数据和编码器 A/B 相，输出包括串口、ADC 控制信号、电机驱动信号和指示灯。

## 代码目录

| 文件 | 内容 |
| --- | --- |
| `top.v` | 顶层连接、模式切换、串口命令和状态上报 |
| `ADC.v` | ADC 数据采集 |
| `encoder.v` | 编码器计数 |
| `key_filter.v` | 按键滤波 |
| `r1_pid.v` | 角度与位置控制计算 |
| `r1_auto.v` | 起摆、捕获和平衡状态控制 |
| `position_profile.v` | 位置目标与速度轨迹 |
| `r1_motor.v` | 电机 PWM 与方向输出 |
| `wrappers.v` | 控制与电机模块接口适配 |
| `serial_link.v` | 串口收发与状态帧 |
| `uart_rx.v` | UART 接收 |

## 源码中的默认值

`top.v` 复位时设置 `center=3200`、`kp=50`、`kd=244`、`kpp=25`、`kdp=600`、`launch_step=383`。位置控制的默认 `counts_per_revolution=1000`，可通过串口命令修改。`serial_link.v` 中的串口接收配置为 230400 bps、50 MHz 时钟。这些是源码初始值，不代表实测标定值。

编码器每圈计数、物理零位和方向应以实机标定为准。10 位 `adc_data_in` 是 ADC 原码，不是编码器计数。

## 文件范围

本次提供的压缩包只有上述 11 个 Verilog 文件，没有 Gowin 工程文件、引脚约束、位流或测试记录。演示视频见 `演示视频.mp4`。仓库中的源码与视频按收到的原文件保存。
